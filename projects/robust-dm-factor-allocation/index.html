Robust DM Factor Allocation

A historical walk-forward study of robust allocation methods for developed-market equity factor indices, with explicit portfolio constraints, trading costs and sensitivity checks.

GitHub Repository In progress

Overview

A portfolio problem under estimation uncertainty

The project asks whether long-only factor indices can be combined more robustly than simple allocation rules. Value, Momentum, Quality, Minimum Volatility and Equal Weight form the allocation universe, while MSCI World remains outside the portfolio as the market benchmark.

The evaluation is historical and pseudo-out-of-sample. Every portfolio uses only information available before the return month, but the full dataset was available while the research design was developed.

Methods

Simple baselines and covariance-based portfolios

The default specification uses a 120-month estimation window, quarterly rebalancing, a 40% weight cap and 10 basis points of portfolio trading costs.

Equal Weight

A transparent 1/N baseline with no estimated risk inputs.

Inverse Volatility

Scales each sleeve by its estimated standalone risk.

Sample GMV

Minimizes portfolio variance using the sample covariance matrix.

Shrinkage GMV

Regularizes covariance estimates to reduce unstable allocations.

Equal Risk Contribution

Balances ex-ante risk contributions across the factor sleeves.

Public release

Why there is no performance chart here

The public release is limited to implementation, tests, configuration and research documentation. MSCI source files, processed return series, portfolio returns, weights, tables and figures are deliberately not redistributed.

The repository is currently being published in stages. Once complete, users with appropriate data access can reproduce the empirical outputs locally by following the documented file names and notebook order.

This is an independent research project, not investment advice, and is not sponsored, endorsed or reviewed by MSCI.

What the code demonstrates

Research and implementation

  • Strict lagging to prevent direct look-ahead
  • Constrained portfolio optimization
  • Turnover based on drifted pre-trade weights
  • Transaction-cost and parameter sensitivity
  • Automated tests for metrics and constraints

Limitations

How to read the study

  • Several histories include provider-backtested periods
  • Index returns are not investable product returns
  • Equal Weight is only an approximate size tilt
  • The scope is one provider, currency and market aggregate
